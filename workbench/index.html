Browser & web analysis

Inspect sites you own or are authorized to examine. Workflows run through the local REA CLI or MCP tools.

01 — 04
LOCAL CHROME · READ ONLY

Inspect a live Chrome tab

Connect to your own Chrome remote-debugging endpoint to list tabs, extract the current page text, and capture a screenshot. Start Chrome with port 9222 and a separate profile; this tool only accepts loopback connections.

Local connection only
◎
WEB PAGE

Inspect a website

Inspect a page from your locally running Chrome DevTools Protocol endpoint.

rea inspect-web-page "http://127.0.0.1:9222" "TARGET_ID_FROM_LIST" --json

Find the target ID with rea list-browser-targets "http://127.0.0.1:9222".

⌖
BROWSER SESSION

Capture browser behavior

Generate a bounded scenario for your local Chrome-family browser. The template opens a URL and retains a final URL snapshot.

rea capture-browser-scenario .\scenario.json --json
⌁
ELECTRON APP

Trace app modules

Map JavaScript modules, imports, routes, IPC boundaries, and native add-ons.

rea analyze-javascript-application "D:\apps\your-app" --json
↳
CAPTURE FILE

Analyze a HAR capture

Review a saved network capture locally; preserve request and response evidence.

rea inspect-web-network-capture "D:\captures\session.har" har --json

PUBLIC WEB PAGES

Web scraper

Fetch up to 10 public HTML/text pages at a time. Extract titles, descriptions, headings, links, and readable text, or target a CSS selector.

03 — 06
PUBLIC REPOSITORIES

GitHub explorer

Find public projects and inspect recent releases and open issues using GitHub’s official API. No token required for public repositories.

04 — 07
RSS · ATOM · SYNDICATED CONTENT

Feed collector

Collect up to 50 recent entries, titles, dates, links, and summaries from a public RSS or Atom feed.

05 — 07
OFFICIAL YOUTUBE DATA API

YouTube video collector

Search public videos and collect descriptions, channel, publish date, duration, view counts, and caption availability. Configure a YouTube Data API key to enable.

06 — 07
YOUR MAILBOX · READ ONLY

Gmail extractor

Search, open full message text, and download attachments after Google OAuth consent. Read-only scope: the app cannot send, label, or delete mail.
